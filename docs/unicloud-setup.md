# uniCloud 配置

项目已经按 uniCloud 方案加入云对象和数据库 schema。当前不接微信支付，订单创建后直接进入“待备货”。

## 1. 创建服务空间

在 HBuilderX 中打开项目，右键项目根目录，选择“创建 uniCloud 云服务空间”，选择阿里云或腾讯云均可。创建后将服务空间绑定到项目。

## 2. 上传云端资源

上传以下目录：

`uniCloud-aliyun/cloudfunctions/shop`

并将 `uniCloud-aliyun/database` 下的四个 schema 上传到云数据库：

- `fresh_products`
- `fresh_users`
- `fresh_addresses`
- `fresh_orders`

## 3. 配置管理员

在 `shop` 云对象的环境变量中设置：

`FRESH_ADMIN_KEYS=自行生成的一段随机字符串`

也可以设置：

`FRESH_ADMIN_OPENIDS=管理员微信openid`

不要把管理员密钥写进前端代码。云对象的 `adminSeedProducts`、`adminList`、`adminUpdateProduct` 和 `adminUpdateOrderStatus` 都会校验管理员权限。

## 4. 初始化商品

服务空间和 schema 上传完成后，首次调用 `getStoreData` 或 `adminList` 会自动写入 32 个示例商品。重复读取不会重复写入。管理员不应把密钥写入项目文件，应只在服务空间环境变量中配置 `FRESH_ADMIN_KEYS`。

## 5. 当前订单规则

- 商品金额满 29 元免配送费，否则配送费 3 元。
- 配送时段固定为“今天 10:00-12:00”和“今天 16:00-19:00”。
- 下单后状态为“待备货”。
- 管理员可更新为“配送中”“已完成”“已取消”“退款申请中”“已退款”或“退款驳回”。
- 云端以下单时的数据库商品价格和库存为准，前端传入的价格不会被信任。

## 6. 微信开发者工具

绑定服务空间后，必须从 HBuilderX 的“运行”菜单启动项目：

1. 右键项目中的 `uniCloud-aliyun`，确认已关联服务空间。
2. 点击顶部“运行”→“运行到小程序模拟器”→“微信开发者工具”。
3. HBuilderX 会自动生成并打开微信小程序项目，再点击“编译”。

不要使用 `npm run build:mp-weixin` 后手动导入 `dist/build/mp-weixin` 来联调 uniCloud；这种方式不会注入 uniCloud 运行时，前端会回退到本地演示数据。

## 7. 小程序商家管理

小程序的“我的订单”页面提供“店铺管理”入口。进入后输入服务空间环境变量 `FRESH_ADMIN_KEYS` 中配置的一项管理密钥，即可在线管理商品上下架、售价、库存和订单状态。

- 管理密钥仅在当前页面内存中使用，不会写入小程序代码或本地缓存；
- 普通用户即使打开管理页面，也无法通过云对象权限校验；
- 修改商品或订单状态后，云端数据库会立即更新；
- 修改前端页面后需重新运行到微信开发者工具；修改 `shop` 云对象后才需要重新上传部署云对象。

真实上线前仍需在微信公众平台配置隐私协议、用户隐私保护指引和合法业务域名。本项目当前没有真实支付流程。
